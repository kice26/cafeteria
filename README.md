# 한국교육과정평가원 구내식당 메뉴 PWA

휴대폰의 브라우저에서 열어 홈 화면에 추가하면 앱처럼 사용할 수 있는 식단표입니다. `menu.json`은 항상 네트워크에서 새로 불러오므로, 새 식단이 배포된 뒤 사용자가 앱을 다시 열면 최신 메뉴가 표시됩니다.

## 최초 배포 (한 번만)

1. GitHub에서 새 **Public** 저장소를 만들고, 이 폴더 안의 모든 파일을 저장소 최상단에 업로드합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. Actions 탭에서 `Deploy PWA to GitHub Pages`가 완료되면, 표시된 웹 주소를 사용자에게 공유합니다.
4. 휴대폰에서 그 주소를 연 뒤 Safari는 **공유 → 홈 화면에 추가**, Chrome은 **메뉴 → 앱 설치(또는 홈 화면에 추가)**를 선택합니다.

## 매주 식단 업데이트

GitHub 웹사이트에서 `data/weekly_menu.xlsx` 파일을 새 주의 엑셀 파일로 **교체하여 커밋**하세요. 그 한 번의 업로드만으로 다음 과정이 자동 실행됩니다.

1. `Update menu data`가 엑셀에서 날짜별 메뉴를 읽어 `menu.json`으로 변환합니다.
2. 변환된 메뉴 데이터가 저장소에 자동 저장됩니다.
3. `Deploy PWA to GitHub Pages`가 사이트를 새 버전으로 배포합니다.

보통 몇 분 뒤 앱을 다시 열면 최신 식단이 표시됩니다. 업로드하는 엑셀은 이번에 제공한 식단표와 같은 열·행 구조여야 합니다. 연도가 현재 연도와 다를 경우, Actions의 Variables에 `MENU_YEAR` 값을 설정하면 됩니다.
